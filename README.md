Это мой учебный проект — блог-сайт. Я использовал Tailwind CSS, чтобы быстрее стилизовать, и JavaScript для всей логики — например, посты хранятся в localStorage, чтобы не терялись при перезагрузке. Сайт полностью адаптивный, то есть он нормально работает и на компьютерах, и на телефонах.

Что умеет сайт: Главная страница показывает все посты с заголовком, описанием и картинкой. Есть кнопка «Читать дальше», которая открывает отдельную страницу с полным текстом поста. Админ может добавлять новые посты, редактировать их и удалять. Всё хранится в localStorage, поэтому даже без базы данных посты не исчезают при перезагрузке. Есть переключатель тёмной/светлой темы, чтобы каждый мог выбрать, как удобнее.
